# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Instead, use
[GitHub's private vulnerability reporting](https://github.com/Lueyu/daily-portfolio-analysis/security/advisories/new)
for this repository, or email the owner via the address on the GitHub profile.

Include what you can of: reproduction steps, affected endpoints/files, and
impact. A proof of concept is appreciated but not required.

## Scope notes

- This is a personal self-hosted project; there is no hosted multi-tenant
  deployment maintained by the maintainers.
- Reports about the demo dataset being fictional data are not security issues —
  by design it contains no real holdings.
