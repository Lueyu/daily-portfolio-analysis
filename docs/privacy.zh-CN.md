# 隐私与数据流向

[English](privacy.md) · [安全说明](../SECURITY.md) · [自托管指南](self-hosting.zh-CN.md)

**研究团队连接与工具：**额外保存的模型 Key 与默认 Key 使用同样的服务端加密。每个所选供应商会收到对应成员的有限研究上下文，包括相关用户留言与前序发言。可选 DeepSeek 网页检索会发送股票代码和限定长度的查询，并单独记录请求用量；SEC 请求只包含公开发行人标识。团队配置、消息、引用证据与报告存储在你的实例中。详见[数据源边界](research-data.md)。

吵股可以部署在你控制的基础设施上。数据控制权来自**谁在运营这个实例**，并不意味着服务器无法读取数据。

本文说明当前仓库的技术行为，帮助你判断是否适合存放真实持仓。它不是所有吵股网站通用的隐私政策，也不是合规声明。项目处于公开测试阶段，下文列出了尚未完成的能力。

## 谁能接触你的数据？

| 使用方式 | 实际边界 |
|---|---|
| **自己部署** | 记录保存在你的 PostgreSQL 数据库及你创建的备份中。仓库没有内置向维护者集中收集记录的服务，安装项目也不会自动赋予维护者访问权。云主机供应商及拥有服务器、数据库、备份权限的人仍在信任范围内。 |
| **使用别人运营的实例** | 运营者会在其基础设施上接收、存储和处理账号及投资组合记录。运营者可以访问数据库和服务器密钥。应用中的账号隔离无法阻止基础设施管理员读取数据。 |
| **使用外部集成** | 相关数据还会发送给所选模型、金融数据、通知或 Agent 服务，其后续处理不受本仓库控制。 |

**API key 加密存储不等于零知识。** 服务器持有解密密钥，调用供应商时会解密凭证。能够同时访问数据库和服务器密钥的运营者也能解密。投资组合记录没有端到端加密。

## 保存了什么，保存在哪里？

下表中的“实例数据库”，在自建时指你的数据库，在他人托管时指运营者的数据库。

| 数据 | 保存与处理方式 |
|---|---|
| 账号 | 用户名、显示名称、bcrypt 密码哈希、SHA-256 恢复码哈希、会话版本及时间戳保存在实例数据库。注册不要求手机号、真实姓名或经过验证的邮箱。可选通知收件人可能包含邮箱。 |
| 投资组合 | 持仓、现金账户、交易、自选、日志、快照、导入记录及导入历史保存在实例数据库。自由文本可能包含你主动输入的个人信息。 |
| 研究与自动化 | 报告、证据、模型生成的论点与摘要、风控结果、执行步骤、运行事件、策略规则及 Agent Builder 偏好和提示词保存在实例数据库。报告会区分基础规则与 AI 分析。 |
| 投委会讨论 | 完整用户留言、成员名字与偏好、冻结的配置及版本、候选订单、采集证据快照、成员回复和报告版本保存在实例数据库。新输入使旧结论失效后，旧修订仍会保留。获批报告可以关联模拟订单。 |
| 模型预算 | 按用户保存限额、可选估算单价、模型及任务标识、调用用途、预留／供应商返回的 Token 数、状态和时间戳。预算台账本身不保存提示词正文。失败或中断请求可能保留其预留用量。 |
| 模拟交易 | 模拟账户、持仓、订单、成交、提案及手动成交回录保存在实例数据库。模拟数据与真实持仓、交易流水使用不同的数据表。 |
| 已保存的 LLM / Finnhub 凭证 | 使用 AES-256-GCM 加密后存入实例数据库。设置接口返回状态和遮盖后的尾号，不返回完整密钥。调用供应商时由服务器解密。 |
| 通知配置 | 收件地址、Webhook URL、机器人 token、SMTP 凭证等保存在实例数据库。**这些字段目前没有使用 LLM/Finnhub 的应用层加密机制**，并会返回给所属用户的渠道设置页面。 |
| 浏览器存储 | 登录访问令牌、刷新令牌、界面偏好，以及截图识别的接口地址、模型和 API key 保存在浏览器 local storage。截图识别凭证与保存的分析凭证相互独立。 |
| 截图识别 | 图片和识别凭证经过实例服务器，再发给所选视觉模型接口。当前识别处理器不会把这些输入持久化到数据库；确认导入后的持仓行和导入历史会保存。 |
| 运行数据 | 应用会输出浏览器控制台日志和服务器日志。登录限流会在服务器内存中短暂保存基于 IP 的计数。运营者、反向代理、主机及外部供应商可能另外保留请求或错误日志。 |

仓库没有内置分析统计 SDK 或集中使用量上报服务。**这不代表没有日志、网络请求或第三方记录。** 具体部署也可能自行增加监控。

## 哪些操作会向外发送数据？

| 操作 | 接收方与发送内容 |
|---|---|
| 行情、股票搜索与汇率更新 | 腾讯、新浪、Yahoo 等公开行情源接收股票代码或搜索词；Frankfurter 接收币种查询。供应商也会看到正常的连接信息。基础模式、未填写个人 API key 时仍有这些请求。部分公开行情与搜索接口目前使用 HTTP。 |
| AI 分析 | 当前生效的模型接口接收研究提示词、证据及选取的组合上下文，可能包含持仓、数量、成本、市值和组合权重；请求还会携带用于认证的供应商密钥。 |
| Agent Builder AI 审核 | 启用后向模型发送自定义提示词和候选信号上下文。显式规则本身不需要调用 LLM。 |
| 投委会 | 当前模型收到成员偏好、配置／候选上下文、选取的证据摘录，以及请求中包含的完整用户留言；组合经理还会收到前序成员观点摘录。暂停无法撤回已经发送的请求。即使仅向模型发送摘录，完整讨论记录和证据快照仍保存在实例数据库。 |
| Finnhub 研究 | 配置后向 Finnhub 发送 API key，以及公司或标的查询。 |
| 截图识别 | 完整提交图片、提取提示词和识别 API key 经由实例服务器发送给所选视觉模型。提交前请裁剪无关的姓名、账号、余额等信息。 |
| 通知 | 启用的 Webhook、Bark、Server酱、SMTP 或 Telegram 渠道接收事件消息及必要的路由、认证信息。提案通知可能包含标的、方向、模拟数量和理由。渠道测试也会发送消息。 |
| 外部 Agent | 获得会话 token 的 Agent 可以读取其获准工具提供的数据。Agent 及其使用的外部模型有各自的数据处理方式。可选的旧版网关是另一个由运营者控制的集成。 |

模型和金融数据连接测试也可能请求供应商并产生用量。供应商的保留时间、数据用途应以其自身条款为准；应用不能替供应商设定规则，也不能撤回已经发送的数据。

研究预算覆盖共享服务端 LLM 客户端的调用，包括模型连接测试和重试。截图识别／OCR 使用独立路径，不在预算覆盖范围。保守预留用量和用户填写单价得出的估算费用不是供应商账单，详见[投委会与预算指南](investment-council.zh-CN.md)。

### 基础模式与运营者提供的模型

分析优先使用你保存的个人模型配置。没有个人配置时，如果运营者设置了 `DOUBAO_API_KEY`，就会使用该服务器模型。两者都未配置时，实例服务器按规则生成基础报告，不调用 LLM；行情和汇率仍可能出网。

**删除个人模型配置，可能重新启用运营者提供的模型。** 这不是“关闭所有 AI”的开关。当前应用尚未提供针对此回退行为的独立用户同意开关。运行分析前，请在「设置」中查看当前生效的配置。已保存的密钥无法解密时，分析会停止并要求重新录入，不会悄悄改用运营者模型。

## 现在可以使用的控制

- **设置：** 查看当前集成来源，替换或删除 LLM/Finnhub 配置。删除 Finnhub 后恢复公开数据源。若要撤销密钥本身，还需到供应商处操作。
- **通知与 Agent：** 停用或删除通知渠道；暂停 Agent Builder、关闭其 AI 审核或提案通知；撤销不再需要的 Agent 会话。
- **投委会与预算：** 暂停讨论、关闭某个 Builder 配置的投委会、修改账号模型限额。暂停阻止后续工作，已发送的请求仍可能完成。完整留言和报告历史继续保留，恢复讨论也不会重置任务额度。
- **账号恢复：** 离线保存一次性恢复码。账号恢复会重设密码、更换恢复码，并撤销此前的账号和 Agent 会话。使用密码生成新恢复码会替换旧码并撤销此前的账号会话。目前没有邮箱找回流程。
- **当前浏览器：** 退出登录会清除会话令牌。要清除本地保存的识别凭证与偏好，请清除本站浏览器存储；仅退出登录不会清除所有这些内容。
- **自己的实例：** 控制数据库权限、备份、日志、注册开放状态和集成环境变量。妥善备份设置加密密钥；更换或丢失密钥后，原有供应商凭证将无法解密，用户需要重新填写。

## 保留时间与当前缺口

项目**尚未实现通用的数据保留期限或自动清理机制**，覆盖投资组合记录、报告、日志和备份。实际保留时间取决于实例和运营者。删除当前记录或配置，不会同时删除备份、日志或外部供应商中的副本。

完整的自助账号注销与数据清除、全账号数据导出尚未提供。全面的管理员访问审计及隐私同意界面也尚未完成。现有分析运行事件不等于对每次管理员或数据库访问的审计。不要因为文档列出了这些缺口，就认为托管实例已经提供对应能力。

如果为他人运营实例，请在邀请用户前另行发布**真实的实例隐私说明**：写明运营者、实际联系方式、数据和备份位置、日志及保留方式、启用的供应商及模型回退行为，以及导出或删除请求的处理方式。不要照搬“数据库只掌握在用户手里”的自建措辞。本仓库不据此确认任何官方托管服务，也不提供虚构的运营主体、联系方式或条款。
